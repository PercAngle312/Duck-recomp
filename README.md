# Duck Dodgers — Native PC Recompilation

Development repository for a native Duck Dodgers PC recompilation. Linux is the reference runtime; Windows x64 is under development.

## Status

- Linux: previously rebuilt and gameplay smoke-tested.
- Windows: first Windows SDK compilation and memory-alias validation are not yet verified.
- Original game ROM and proprietary assets are **not** stored in this repository.

Build integration source: Phase 11 Windows CMake checkpoint. The Windows CI workflow will be added separately and run only when its required sources are present.
